 Experiment 7 — PostgreSQL Triggers

## 📘 Objective

This experiment demonstrates how to create and use **PostgreSQL triggers** to monitor data changes in database tables.  
It consists of two parts:

1. **EduSmart Institute** – Monitoring insertions and deletions in the `student` table.  
2. **TechSphere Solutions** – Maintaining an automatic audit trail for employee additions and deletions.
